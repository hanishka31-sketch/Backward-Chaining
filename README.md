### Student Academic Guidance – Backward Chaining

This project implements a **Backward Chaining** approach to determine whether a student is **eligible for placement**.

* **Facts:** CGPA, attendance, backlogs, mini project, and coding problems are defined as facts.
* **Rules:** Academic performance and practical skills are derived from these facts.
* **Backward Chaining:** Starts with the goal `EligibleForPlacement` and checks whether all required conditions can be proved.
* **Final Result:** If all conditions are satisfied, the student is declared **Eligible for Placement**.
